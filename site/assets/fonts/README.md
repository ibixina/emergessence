# Sketchbook lettering

Reenie Beanie by James Grieshaber supplies the notebook's live text. The local font is unmodified and licensed under the SIL Open Font License 1.1. The full license is in `ReenieBeanie-OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/reeniebeanie

Font file: https://raw.githubusercontent.com/google/fonts/main/ofl/reeniebeanie/ReenieBeanie.ttf

The CSS uses regular weight without synthesized bold or italic. Text remains selectable, searchable, responsive, and accessible.
